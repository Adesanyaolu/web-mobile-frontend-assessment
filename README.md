# Web & Mobile Frontend Assessment

This repository contains the technical assessment for a front-end web and mobile development role. It contains two main applications that manage their own dependencies independently to avoid conflicts.

## Projects

- **Web App** (`apps/web`): A Next.js application.
- **Mobile App** (`apps/mobile`): An Expo (React Native) application.

## Getting Started

Each application is self-contained. You must navigate to the respective directories to install dependencies and run the development servers.

### Web

```bash
cd apps/web
npm install
npm run dev
```

### Mobile

```bash
cd apps/mobile
npm install
npx expo start
```
